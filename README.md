 Estilos de Caixa - CSS Box Model
Este projeto consiste numa página web desenvolvida em HTML5 e CSS3, criada para demonstrar de forma visual e prática os conceitos fundamentais do Box Model (Modelo de Caixa) no CSS, incluindo espaçamentos, bordas, margens e transbordo.
 Sobre o Projeto
A página apresenta uma interface moderna com cartões organizados em grelha, exibindo 6 exemplos práticos de como propriedades de estilização afetam o comportamento e o posicionamento dos elementos na web.
🛠️ Tecnologias Utilizadas
 HTML5: Estruturação semântica da página.
 CSS3: Estilização avançada, utilizando:
   Variáveis CSS (:root) para padronização de cores e tons.
   CSS Grid para a disposição responsiva dos cartões.
  Modelo de Caixa (Box Model) (width, height, padding, border, margin, overflow).

 Exemplos Demonstrados
 
Cada secção aborda uma propriedade ou combinação específica do modelo de caixa:
  
  Exemplo 1: Transbordo (overflow)
    
    Demonstra como o conteúdo se comporta ao exceder as dimensões fixas da caixa.
  
   Exemplo 2: Espaçoso (padding)
    
     Mostra a aplicação de espaçamento interno utilizando unidades relativas (em).
   
   Exemplo 3: Borda e Espaçamento (border + padding)
    
     Combina uma borda destacada com preenchimento interno.

  Exemplo 4: Margem, Borda e Espaçamento (margin)
    
    Introduz o conceito de margens externas utilizando guias visuais tracejadas.

   Exemplo 5: Borda Tracejada e Margem Larga
 
    Utiliza bordas tracejadas e margens laterais amplas para criar espaço ao redor do elemento.

Exemplo 6: Centralização Automática (margin: 0 auto)
    
    Demonstra o método padrão de centralização horizontal de elementos em bloco.
